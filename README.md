The Urgency Queue project is assigned to students in the Fall 2026 CSCI 1302
classes at the University of Georgia. **Students who are assigned this project
are expected to read the entire project description before beginning their
project.**

Please see the complete [Urgency Queue project description](https://cs1302book.com/projects/cs1302-urgency/cs1302-urgency-index.html)
for requirements, milestones, testing instructions, and submission instructions.

This repository contains the student starter files and
[`cs1302-urgency-queue.jar`](cs1302-urgency-queue.jar). Documentation for the
provided types is available in the [API documentation](https://cs1302uga.github.io/cs1302-urgency-queue/).
